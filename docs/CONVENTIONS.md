# Ndamba app: build conventions (read first)

This repository is one codebase with four products (naming, October 2026: app **Ndamba**, children's saga **Lionceaux**, coaching book **Le Code Njangi**, agent **Mola**; the philosophy and the Indice Njangi keep the Njangi name), owned by William Foteping (Lemon Network Solutions, Maryland, Cameroonian heritage):
1. **Lionceaux, tome 1 : Le Ballon qui voyage** (French children's novel starring Kaydoudou & BriBri, `tome1/`), read in the browser at `/book/tome1/`.
2. **Le Code Njangi. Posséder avec intention** (coaching book, `coach/`), read at `/book/methode/`; its 50 drills (`coach/drills/*.json`) power the app.
3. **The Ndamba app** (`app/`): a premium, bilingual (French first, English second) app for players, coaches and analysts, comparable to the best all-in-one football apps: drill library, session builder, week planner (periodization), player development, team and match setup, live match tagging that produces a "team philosophy" report (the Indice Njangi), video analysis, the books.
4. **Mola**: the app's agent. Like a "do-it-for-me" action agent: it onboards new users by conversation (filling their details as they talk) and then *does things* inside the app (builds sessions, plans the week, sets up matches, adds players, drafts convocation messages for approval, opens reports).

Philosophy and mantra (use them, never decorate with them): **« Le ballon doit voyager. Mais il doit savoir où il va. »** and **« Une nation africaine championne du monde en 2030 ou en 2034. »** The Njangi is the Cameroonian tontine: everyone contributes, the pot circulates, everyone benefits; possession must circulate *with a purpose*.

## Stack and files

- `app/`: Vite 5 + React 18 + TypeScript + Tailwind 3 + react-router 6 + Dexie 4 (IndexedDB, local-first) + lucide-react icons + i18next/react-i18next. No other UI library. Do not install packages (if you truly need one, ask in your final report).
- `src/lib/types.ts` data model; `src/lib/db.ts` tables; `src/lib/actions.ts` shared operations (auto sessions, plan week, create team/player/match, auto lineup, convocation text, WhatsApp/SMS/mail links, ICS export); `src/lib/njangi.ts` the Indice Njangi; `src/lib/formations.ts` formation slots; `src/lib/seed.ts` demo data; `src/lib/session.tsx` (`useSession()` gives `{ ready, profile, team, teams }`); `src/lib/config.ts` brand, plans, gates; `src/lib/util.ts` (uid, dates, fmtDate, fmtClock, money, fcfa, download, cx); `src/lib/hooks.ts` (`useLiveQuery(fn, deps, fallback)`, `useDocumentTitle`); `src/lib/pitch.mjs` the shared diagram renderer (generated copy of `tools/pitch.mjs`).
- `src/content/index.ts`: `DRILLS` (the 50 drills, typed `Drill`), `getDrill(id)`, `drillText(drill, lang)`, `LESSONS` (the 40 "Leçons du Ballon" of the novel), `TOME1_TOC`, `METHODE_TOC`, constant lists (FAMILIES, INTENTIONS, SKILLS, MDS). These are GENERATED by `node scripts/build-content.mjs` from the book sources, which writers are still producing: run that command again to refresh (it is safe to run any time). Your pages must handle empty or partial content gracefully.
- `src/ui/index.tsx`: Logo, LogoMark, LangSwitch, PageHeader, Card, CardTitle, Section, Badge (tones neutral/forest/terra/sun/clay/dark/ok), Stat, Progress, EmptyState, Modal, Tabs, Field, Toggle, Segmented, Callout, **Pitch** (`<Pitch spec={diagram} />` draws any pitch diagram exactly like the books).
- CSS helpers in `src/index.css`: `card`, `card-pad`, `eyebrow`, `label`, `input`, `btn-primary`, `btn-accent`, `btn-sun`, `btn-dark`, `btn-ghost`, `btn-outline`, `btn-danger`, `btn-sm`, `btn-lg`, `chip`, `chip-on`, `link`, `prose-n`, `table-n`, `container-page`, `no-print`, `safe-bottom`.
- Tailwind palette: `cream` (page), `paper` (cards), `sand`, `line`, `ink` (DEFAULT/soft/muted/faint), `forest-*` (primary green #1F4D3A), `terra-*` (terracotta #C5762F), `sun-*` (gold #E3A92B), `clay-*` (red #B8432F), `night-*` (dark #101814). Green, red and gold are also the colours of Cameroon: use them with taste. Fonts: `font-display` (Fraunces) for headings, Inter for text.
- Routes are wired in `src/App.tsx`, with one placeholder file per page under `src/surfaces/<surface>/`. **Replace the placeholder files you own; do not edit App.tsx.** Components only your pages use go in `src/surfaces/<surface>/components/`.
- Layouts: `SiteLayout` (public pages) and `AppLayout` (the app: desktop sidebar, mobile bottom tabs and "More" sheet, a floating Mola button). Live tagging (`/app/analyse/live/:id`) renders full screen on a dark background (no sidebar).

## Language (French first, English second)

- **No hard-coded user-facing text.** Every string goes through i18n. Use `const { t, lang } = useT('<your-namespace>')` (from `src/i18n`). Put your strings in `src/i18n/fr/<namespace>.json` and `src/i18n/en/<namespace>.json` (create both, same keys). Shared vocabulary is in the `common` namespace: use `t('common:intentions.fixer')`, `t('common:skills.scan')`, `t('common:families.rondo')`, `t('common:md.MD-3')`, `t('common:events.PASS_OK')`, `t('common:positions.DM')`, `t('common:actions.save')`, `t('common:plans.coach')`, etc.
- French is the reference: write it first, natural and warm; English is a natural translation, not word for word.
- Drill content comes in both languages: `drillText(drill, lang)`.
- **No em dashes (—) or en dashes (–) anywhere in copy, French or English.** Use commas, colons, periods, parentheses, or "to"/"à" for ranges. No emojis.
- Voice: direct, warm, concrete, respectful of African football and of coaches with few resources; no hype words.

## Design

- Premium, warm, editorial. Not a generic dashboard. Think of a beautiful football magazine crossed with a precise tool. Generous spacing, Fraunces headings, real hierarchy, subtle cards, purposeful colour.
- **Mobile-first**: every page must work at 375 px wide with no horizontal scroll; desktop gets more columns. Touch targets at least 44 px on phone. Many users are on Android phones with small data plans: keep pages light, no heavy images, no autoplay.
- Every empty state explains what the page is for and offers the first action.
- Icons: lucide-react only. Diagrams: `<Pitch spec={...} />`. No stock photos.
- Accessibility: labels on inputs, buttons are buttons, alt text, visible focus, sufficient contrast.
- `useDocumentTitle(t('...'))` on each page.

## Data

- Read with `useLiveQuery(() => db.table.where(...).toArray(), [deps], fallback)` so pages update live.
- `const { profile, team } = useSession()`. Inside `/app` the profile always exists (the layout sends users without one to `/bienvenue`); `team` can be null (the user has no team yet): handle it with an empty state that offers to create one (use `createTeam` from `lib/actions`).
- Ids: `uid('prefix_')`. Dates: ISO strings `YYYY-MM-DD` (`todayISO()`, `addDays`, `weekStart`), shown with `fmtDate(iso, lang)`.
- Use the functions in `lib/actions.ts` instead of rewriting them (Mola uses the same ones).
- Premium: `profile.plan` is one of free, player, coach, club, federation. Education is never gated (books, drills, lessons). Advanced tools show a gentle upgrade card linking to `/app/premium` when `profile.plan === 'free'` and a limit in `GATES` is reached; never block the demo (the demo profile is on the coach plan).

## Demo data and testing

- Demo: `seedDemo('coach' | 'player', 'fr' | 'en')` from `src/lib/seed.ts` creates the Lionceaux de Bonamoussadi U13 (the team of Kaydoudou and BriBri in the novel), 15 players with skills, four sessions this week (MD-4 to MD-1), a played match against the Requins de Bépanda (2-1, with a full stream of live tags) and an upcoming match against the Panthères de Deïdo on Saturday.
- In Playwright, after opening any page of your dev server: `await page.evaluate(async () => { const m = await import('/src/lib/seed.ts'); await m.seedDemo('coach', 'fr') })` then navigate. To reset: `await page.evaluate(() => indexedDB.deleteDatabase('njangi'))` then reload. Language: set `localStorage.setItem('njangi.lang','en')` and reload, or click the FR/EN switch.
